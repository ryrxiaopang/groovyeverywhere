# data/

Metadata from the MTG-Jamendo dataset (https://github.com/MTG/mtg-jamendo-dataset): track ids, human genre / mood /
instrument tags and the official train/validation/test splits. Used only for testing; no audio.
Licence: the dataset's annotations are released by the Music Technology Group (UPF) under their own terms;
check the dataset page before making this repository public.
