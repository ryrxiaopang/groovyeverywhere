# data/

Metadata from the MTG-Jamendo dataset (https://github.com/MTG/mtg-jamendo-dataset): track ids, human genre / mood /
instrument tags and the official train/validation/test splits. Used only for testing; no audio.
Licence: the dataset's annotations are released by the Music Technology Group (Universitat Pompeu Fabra) under CC BY-NC-SA 4.0
(non-commercial, share alike, credit the authors). Credit: Bogdanov, Won, Tovstogan, Porter and Serra, "The MTG-Jamendo Dataset for Automatic
Music Tagging", ICML 2019 Machine Learning for Music Discovery Workshop. See `../NOTICE.md`.
