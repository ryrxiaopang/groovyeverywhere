# archive/

One-shot scripts from earlier stages of the project, kept (not deleted) so the history stays readable. Nothing in the current code calls them.
Their jobs are now done by `boost_artists.sh` (named artists), `grow_more.sh` (unattended growth), `build_youtube.py --variety` and `quality_pass.sh`.

To run one again, copy it back to the repository root first (they `cd ~/groovyeverywhere` and use root-relative paths).

| file | what it was |
|---|---|
| boost3.sh, spotify_boost.sh, spotify_boost2.sh | 8 Oct artist additions from the first Spotify artist files |
| style_boost.sh, pop_boost.sh, taste_boost.sh, expand_loop.sh | early search-based pool growth (Japanese soul, pop / R&B / indie pop, long loops) |
| analyse_list_then_pool.sh | analyse one small list before the backlog |
| cc_survey.py | one-off look at Creative Commons music on YouTube (no longer a goal) |
